# Implement Logout — Navbar + Sidebar

## Logout Logic

1. Call `POST /api/auth/logout` (clears refresh token from DB and cookie)
2. Clear `accessToken` from `localStorage`
3. Redirect to `/login`

| 1 | `components/layout/navbar.tsx` | Add `handleLogout` function, attach to Logout menu item |
