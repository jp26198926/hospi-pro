# Plan: Shared document print layout (Receivings + Releasings + future)

**Goal:** Releasings print matches **receivings** layout. Extract a **reusable print builder** so future documents stay consistent.

**Reference layout** (already in `receiving-detail-client.tsx` `handlePrint`):
1. Header — logo + app name/address/phone | **Doc No.** (right, bold blue)
2. Blue rule
3. Title banner — light fill + blue accent + centered title
4. Fields box — 2-column label/value + status badge
5. Section heading + blue underline
6. Items **autoTable** (blue header, 0.0000 numbers, right-aligned qty/cost)
7. Remarks box
8. Signatures — left named user + right blank line
9. Footer — generated timestamp + computer-generated note

---

## Step 1 — Shared library

**Create `lib/print/document-print.ts`** (client-safe; jsPDF + autoTable)

```ts
export type PrintStatus = "Draft" | "Completed" | "Cancelled";

export interface PrintAppSettings {
  appName: string;
  appLogo: string | null;
  address: string | null;
  phone: string | null;
}

export interface PrintField {
  label: string;
  value?: string;
  badge?: PrintStatus; // if set, draw colored badge instead of text
}

export interface PrintTableColumn {
  key: string;
  header: string; // may include \n
  align?: "left" | "center" | "right";
  width?: number;
}

export interface PrintDocumentInput {
  appSettings?: PrintAppSettings;
  documentNo: string;
  documentNoLabel: string; // "Receiving No." | "Releasing No."
  title: string; // "RECEIVING" | "RELEASING"
  fieldsLeft: PrintField[];
  fieldsRight: PrintField[];
  sectionTitle: string; // "Received Items" | "Released Items"
  tableColumns: PrintTableColumn[];
  tableRows: Record<string, string>[]; // keys match column.key
  remarks?: string | null;
  leftSignatureLabel: string; // "Received By:" | "Released By:"
  leftSignatureName?: string;
  leftSignatureCaption?: string; // "Staff Signature"
  rightSignatureLabel: string; // "Verified By:"
  rightSignatureCaption?: string; // "Authorized Signature"
  timezone: string;
  fileName: string; // "RCV-00001.pdf"
}

export function fmtPrintNum(v: string | number): string; // toFixed(4)
export async function loadLogoDataUrl(logo: string | null): Promise<string | null>;
export function statusFill(status: PrintStatus): [number, number, number];
export function printDocumentPdf(input: PrintDocumentInput): void; // draws + doc.save
```

**Implementation:** port geometry/colors from current receivings `handlePrint` (A4, margins 15, BLUE `[44,95,138]`, fields box, autoTable headStyles, remarks, signatures, footer).

- `drawField` for labels; badge path for `PrintField.badge`
- autoTable `columnStyles` from `tableColumns` align/width
- `loadLogoDataUrl` + `statusFill` move **here** (remove duplicates from clients)
