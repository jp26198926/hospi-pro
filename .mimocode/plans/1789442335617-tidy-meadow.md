# Plan: Transfers module (location → location stock transfer)

Copy **Releasings** implementation pattern end-to-end. Difference: **Complete** posts **two** stock_movements lines and updates **both** `stock_levels` rows; **do not** touch `products` stock/costs.

**User decisions**
- **`from_location_id` and `to_location_id` both required**
- Draft cancel: **no stock reverse**
- Sidebar icon: **`map-pin`** (existing)
- List default **Draft**; Trans # **`TRAN-00001`** clickable → detail
- Series **`TI-000001`**
- Status enum: shared **`inventoryStatusEnum`** (`inventory_status`)
- Detail layout + actions + scan: same as `/releasings/[id]`
- Print: **`printDocumentPdf`** (same chrome; title TRANSFER)
- Note 2 in brief is **Cancelled** (Restore only), not Completed

## Step 1 — Schema + migration

### `lib/db/schema.ts` (after releasings)

```ts
export const transfers = pgTable("transfers", {
  id: bigserial("id", { mode: "number" }).primaryKey(),
  date: timestamp("date", { withTimezone: true, mode: "date" }).notNull(),
  fromLocationId: bigint("from_location_id", { mode: "number" })
    .notNull()
    .references(() => locations.id),
  toLocationId: bigint("to_location_id", { mode: "number" })
    .notNull()
    .references(() => locations.id),
  remarks: text("remarks"),
  status: inventoryStatusEnum("status").notNull().default("Draft"),
  createdAt: timestamp("created_at", { withTimezone: true, mode: "date" }).defaultNow().notNull(),
  updatedAt: timestamp("updated_at", { withTimezone: true, mode: "date" }),
  deletedAt: timestamp("deleted_at", { withTimezone: true, mode: "date" }),
  createdBy: bigint("created_by", { mode: "number" }).references(() => users.id),
  updatedBy: bigint("updated_by", { mode: "number" }).references(() => users.id),
  deletedBy: bigint("deleted_by", { mode: "number" }).references(() => users.id),
  deletedReason: text("deleted_reason"),
});

export const transferItems = pgTable("transfer_items", {
  id: bigserial("id", { mode: "number" }).primaryKey(),
  transferId: bigint("transfer_id", { mode: "number" })
    .notNull()
    .references(() => transfers.id),
  productId: bigint("product_id", { mode: "number" })
    .notNull()
    .references(() => products.id),
  qty: decimal("qty", { precision: 10, scale: 4 }).notNull().default("0"),
  dateExpiry: timestamp("date_expiry", { withTimezone: true, mode: "date" }),
  remarks: text("remarks"),
  status: inventoryStatusEnum("status").notNull().default("Draft"),
  // same audit columns as releasing_items
});
```

- **Both locations required** (`.notNull()`)
- No unit cost / total on items
- No `products` update on complete

});

  return `TRAN-${String(id).padStart(5, "0")}`;
}

  return `TI-${String(id).padStart(6, "0")}`;

### `lib/transfers.ts`

### `lib/transfer-stock.ts`
**`completeTransfer(transferId, userId)`** — `db.transaction`:
1. Draft master + Draft items; require `toLocationId`; qty > 0
2. Per item:
   - Check **from** `stock_levels` ≥ qty (else throw)
   - Insert stock_movements **qty: -qty**, location **from**, trans **Transfer**
   - Insert stock_movements **qty: +qty**, location **to**, trans **Transfer**
   - Decrement stock_levels (product + from)
   - Increment stock_levels (product + to); **insert row if missing**
   - **Do not** update `products`
   - Item → Completed
3. Master → Completed

**`cancelCompletedTransfer`** (API-ready; Draft cancel path unused):
- Per completed item: movements **+qty @ from** and **-qty @ to**, trans **Transfer Cancel**; reverse both stock_levels; items + master Cancelled

**Stock check helpers:** copy from `lib/releasing-stock.ts` (`getStockAtLocation`, draft qty sum) but scope to **from** location.

## Step 3 — APIs (mirror releasings)

### Master `app/api/transfers/`
- **GET** list: join from/to locations + users; `transNo`; default status param **Draft**; search location/remarks; filters from/to location
- **POST** create: both locations required, status Draft, `createdBy`
- **[id] GET/PUT/DELETE/PATCH**
  - PUT: Draft only; both locations required
  - DELETE: Draft → cancel items Draft, **no stock**; Completed → `cancelCompletedTransfer`
  - PATCH: Cancelled → Draft; clear deleted_*; restore items
- **[id]/complete POST** → `completeTransfer`

### Items `app/api/transfer-items/`
- **GET** `transferId`; join products + **uoms** → `uomName`; `seriesNo`; `showCancelled`
- **POST** add: parent Draft; qty vs **from** stock + existing Draft qty on same product
- **[id] PUT/DELETE/PATCH** — same Draft guards + stock check on qty changes

Reuse **`GET /api/products/scan?code=&locationId=`** with `locationId = fromLocationId`. Permission: already `/releasings` Read — **add** `/transfers` Read OR use requireAuth OR allow either path. **Plan:** change scan to `requireAuth` or accept both `/transfers` and `/releasings` Read so both modules can scan.

## Complete workflow summary

| Step | Action |
|------|--------|
| 1 | Draft items |
| 2 | stock_movements **-qty** @ **from**, trans Transfer |
| 3 | stock_movements **+qty** @ **to**, trans Transfer |
| 4 | stock_levels decrement @ from |
| 5 | stock_levels increment @ to (create if missing) |
| 6 | **Skip products** |
| — | Item + master → Completed |

Cancel Completed (API): reverse both legs with **Transfer Cancel**. Draft cancel: status only.
