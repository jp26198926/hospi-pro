## Goal

Two read-only report modules, same layout/UX as **`/report-inventory`** (filter card, Generate only, blue results bar + record badge, DataTable, mobile cards, PDF/Excel with **`drawCompanyHeader`**):

1. **Report Low Stock** — `/report-low-stock`
2. **Report Near Expiry** — `/report-near-expiry`

**No new domain tables.** Reuse `stock_levels`, `products`, `inventory_batches`, `locations`, `categories`, `uoms`.

**Confirmed policies**
- Low stock: **per location** — `stock_levels.qty <= products.minStock`

## 1. Report Low Stock

### Data rule

For each `stock_levels` row (Active products/locations):

```
qty <= products.minStock
```

Include products with `minStock = 0` only when `qty <= 0` (still low/out). Optional filter **“Only minStock > 0”** (default **on**) so zero-min products don’t flood the list — **default: on** (only products with minStock > 0).

### Columns

| Column | Source |
|--------|--------|
| # | index |
| Location | `locations.name` |
| Product Code | `products.code` |
| Product Name | `products.name` |
| Category | `categories.name` |
| UOM | `uoms.code` |
| Min Stock | `products.minStock` (`0.0000`) |
| On Hand | `stock_levels.qty` (`0.0000`) |
| Shortage | `max(0, minStock - qty)` (`0.0000`) |

### Filters

- Location (SearchableSelect, all)
- Category (SearchableSelect, all)
- Product (SearchableSelect, all)
- Checkbox/Select: **Min stock defined only** (default Yes)

### API

`GET /api/report-low-stock` — `requirePermission(..., "/report-low-stock", "Read")`

Params: `locationId`, `categoryId`, `productId`, `minStockDefined=1|0`, `page`, `limit`

SQL/Drizzle join stock_levels + products + locations + categories + uoms  
WHERE products.status Active, locations Active, `qty <= minStock` (+ minStock > 0 if defined)

Response: `{ data, total, page, limit }` same as report-inventory

## 2. Report Near Expiry

### Data rule

`inventory_batches` with `status = Active`, `qty > 0`, and:

```
dateExpiry IS NULL → exclude (no expiry to monitor)
OR dateExpiry <= today + N days   // includes already expired
```

**Status column:** `Expired` if `dateExpiry < today` (local/app day start UTC-safe); else `Near Expiry`.

Default **N = 30**; user can set Days (number input or Select 7/14/30/60/90 + custom min 1 max 365).

### Columns

| Column | Source |
|--------|--------|
| # | index |
| Location | locations |
| Product Code / Name | products |
| Category | categories |
| UOM | products.uom → uoms |
| Batch No | `inventory_batches.batchNo` |
| Expiry | `formatDateOnly(dateExpiry)` |
| Days Left | `dateExpiry - today` (negative = overdue); display integer |
| Qty On Hand | `inventory_batches.qty` |
| Status | Expired / Near Expiry (badge red / orange) |

### Filters

- **Days ahead** (default 30)
- Location, Category, Product
- Status: All / Near Expiry / Expired (default All)

### API

`GET /api/report-near-expiry` — `requirePermission("/report-near-expiry", "Read")`

Params: `days=30`, `locationId`, `categoryId`, `productId`, `status=all|near|expired`, `page`, `limit`

Join inventory_batches + products + locations + categories + uoms  
Filter: Active batch, qty > 0, dateExpiry not null, dateExpiry <= now + days

ISO date binds only (learned from report-inventory Date bind bug).

Response: `{ data, total, page, limit }`


Seed: pages `Report Near Expiry`, path `/report-near-expiry`, icon `calendar-clock` or `clock`, Admin View+Read
