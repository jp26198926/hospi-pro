# Plan: Default last 20 + date desc — `/conversions`, `/stock-levels`, `/stock-movements`

## Goal

Same as `/adjustments` after the last change:
- On load: **last 20** rows
- **Descending** by the module’s default sort column (newest first)
- **No extra filters** until Advanced Search (Clear returns to the same defaults)

Reference: `components/adjustments/adjustments-table.tsx` (limit 20, status `all`, empty-sort → `desc`, Show `[20, 25, 50, 100]`).

## Current vs target

| Module | Sort default | Now | Target |
|--------|--------------|-----|--------|
| `/conversions` | `date` | limit 10, status **Completed**, empty sort → **asc** | limit **20**, status **all**, empty sort → **desc** |
| `/stock-levels` | `updatedAt` | limit 10, empty sort → **asc** | limit **20**, empty sort → **desc** (last updated first) |
| `/stock-movements` | `date` | limit 10, empty sort → **asc** | limit **20**, empty sort → **desc** |

APIs already default `sortOrder` to `desc`; they default `limit` to **10**. Conversions API defaults status to **Completed** — change to **`all`**. Stock-levels/movements have no status filter.

## Universal table edits

In each `*-table.tsx`:

1. `const [limit, setLimit] = useState(20);`
2. Empty sorting → desc:

```ts
const sortOrder = sorting[0]
  ? sorting[0].desc
    ? "desc"
    : "asc"
  : "desc";
```

3. Show Select options: `[20, 25, 50, 100]` (include 20).
