# Products Advanced Search — Add GST Type filter

## Changes

### 1. `components/products/product-search-modal.tsx`

- Fetch gst-types on open: `fetch("/api/gst-types?status=Active&limit=100")`
- Add `gstTypeFilter` state (default `"all"`)
- Add SearchableSelect for GST Type (allOption, "All")
- Update `onSearch` callback signature: `(term, status, categoryId, gstTypeId)`
- Clear resets gstTypeFilter to `"all"`

### 2. `components/products/products-table.tsx`

- Add `gstTypeFilter` state
- Pass `gstTypeId` query param to API when filter is not `"all"`
- Update `onSearch` handler to accept and set gstTypeFilter

### 3. `app/api/products/route.ts`

- Read `gstTypeId` query param
- Add condition: `eq(products.gstTypeId, parseInt(gstTypeId))` when set

## Verification

1. Open Products → Advanced Search → GST Type dropdown appears with all active GST types
2. Select a GST type → Search → table filters by that GST type
3. Clear → shows all products
