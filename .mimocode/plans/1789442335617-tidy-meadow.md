# Fix: collapsed sidebar hover popover clipped by overflow

## Problem

The collapsed-sidebar hover context menu already exists (`sidebar.tsx` lines 236-255, uses `group-hover:block`). But adding `overflow-y-auto` to the nav in the previous change broke it: CSS forces `overflow-x` to compute as `auto` when `overflow-y` is not `visible`, so the popover (positioned at `left-full`, outside the sidebar) gets clipped.

## Fix

**File:** `components/layout/sidebar.tsx`

Make `overflow-y-auto` conditional — only when the sidebar is expanded. When collapsed (60px icons only), overflow is rarely needed and the popover must not be clipped.

Line 192, change:
```
<nav className="flex-1 overflow-y-auto sidebar-scroll py-2">
```
to:
```
<nav className={cn("flex-1 py-2", !collapsed && "overflow-y-auto sidebar-scroll")}>
```

No other changes needed — the hover popover markup is already correct.

## Verification

1. Collapse the sidebar (chevron button)
2. Hover over a parent icon with children (e.g. Administration) → white popover appears to the right with child links
3. Click a child link → navigates and closes
4. Expand the sidebar → nav scrolls when overflowing; logo/logout pinned
