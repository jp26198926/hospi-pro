# Suppliers Module + Audit Fields Standard

## New pattern: audit fields for all future modules

Every soft-deletable module table now includes:

```
createdBy   integer  FK → users.id  notNull  (set to logged-in user on POST)
updatedBy   integer  FK → users.id  nullable (set to logged-in user on PUT)
deletedBy   integer  FK → users.id  nullable (set to logged-in user on DELETE)
deletedReason text                  nullable (set on DELETE via optional body)
```

**API behavior:**
- POST: `createdBy = auth.userId` (from `requirePermission` return value)
- PUT: `updatedBy = auth.userId`
- DELETE: `deletedBy = auth.userId`, `deletedReason = body.reason || null` (DELETE now accepts optional JSON body)
- PATCH (restore): `deletedBy = null`, `deletedReason = null`, `updatedBy = auth.userId`

## Suppliers module

### Schema — `lib/db/schema.ts` (append)

```ts
export const suppliers = pgTable("suppliers", {
  id: serial("id").primaryKey(),
  name: text("name").notNull().unique(),
  contactPerson: text("contact_person"),
  phone: text("phone"),
  email: text("email"),
  status: commonStatusEnum("status").notNull().default("Active"),
  createdAt: timestamp("created_at", { withTimezone: true, mode: "date" }).defaultNow().notNull(),
  updatedAt: timestamp("updated_at", { withTimezone: true, mode: "date" }),
  deletedAt: timestamp("deleted_at", { withTimezone: true, mode: "date" }),
  createdBy: integer("created_by").references((): AnyPgColumn => users.id),
  updatedBy: integer("updated_by").references((): AnyPgColumn => users.id),
  deletedBy: integer("deleted_by").references((): AnyPgColumn => users.id),
  deletedReason: text("deleted_reason"),
});
```

### Validation — `lib/validations/supplier.ts`

- `supplierSchema`: name (required, max 150), contactPerson (optional, max 100), phone (optional, max 30), email (optional, email, max 150)
