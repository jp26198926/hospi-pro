# Locations Module — Full CRUD

Standard CRUD module: `name` (unique, required) + `status` (commonStatusEnum, default Active). Follows MODULE_CREATION.md pattern with RBAC enforcement.

## Files to create/modify

### 1. Schema — `lib/db/schema.ts` (append)

```ts
export const locations = pgTable("locations", {
  id: serial("id").primaryKey(),
  name: text("name").notNull().unique(),
  status: commonStatusEnum("status").notNull().default("Active"),
  createdAt: timestamp("created_at", { withTimezone: true, mode: "date" }).defaultNow().notNull(),
  updatedAt: timestamp("updated_at", { withTimezone: true, mode: "date" }),
  deletedAt: timestamp("deleted_at", { withTimezone: true, mode: "date" }),
});
```

Then `npm run db:push`.

### 2. Validation — `lib/validations/location.ts` (new)

```ts
export const locationSchema = z.object({
  name: z.string().min(1, "Location name is required").max(100),
});
export const locationUpdateSchema = z.object({
  name: z.string().min(1, "Location name is required").max(100),
  status: z.enum(["Active", "Deleted"]).optional(),
});
export type LocationInput = z.infer<typeof locationSchema>;
export type LocationUpdateInput = z.infer<typeof locationUpdateSchema>;
```

### 3. API list+create — `app/api/locations/route.ts` (new)

- GET → `requirePermission(request, "/locations", "Read")` — pagination/search/status filter
- POST → `requirePermission(request, "/locations", "Add")` — uniqueness check excluding Deleted

### 4. API single — `app/api/locations/[id]/route.ts` (new)

- GET → Read, PUT → Edit, DELETE → Delete (soft), PATCH → Restore

### 5. Components — `components/locations/` (5 new files)

- `locations-columns.tsx` — `Location` interface, `getColumns`
- `locations-table.tsx` — `LocationsTable` (accepts `timezone` prop)

Copy from `components/categories/` as template (adjust field names: `name` not `category`, no `type`/`description`).

### 6. Pages — `app/(admin)/locations/` (3 new files)

- `layout.tsx` — passthrough
- `page.tsx` — `requirePageRead("/locations")` + `getAppTimezone()` + pass timezone to table
- `[id]/page.tsx` — detail page with `requirePageRead` + `formatDateTimeLong`

### 7. Sidebar registration

Insert into `pages` table: `('Locations', '/locations', 'map-pin', <order>, 'Active')` under Data parent (id=8).

### 8. Admin role grants

Grant Administrator all permissions on the new Locations page row (Add, Edit, Delete, Restore, View, Read, Export).
