# Plan: List Export PDF/Excel for `/transfers`, `/releasings`, `/receivings`

## Goal

Same client-side list export as `/adjustments` and `/conversions`: toolbar **PDF** + **Excel** on each document list, current page data, **Status** included. Not detail-page `printDocumentPdf`.

Reference implementation: `components/adjustments/adjustments-table.tsx`, `components/conversions/conversions-table.tsx`.

## Pattern (apply identically per module)

1. **Imports** in `*-table.tsx`: `FileDown`; `jsPDF`; `autoTable`; `* as XLSX`; `formatDateOnly` from `@/lib/datetime`.
2. **`exportPDF`**: landscape jsPDF; title `"<Module> Report"`; autoTable head/body from `data`; `styles: { fontSize: 8 }` (fewer columns than adjustments); `doc.save("<file>.pdf")`.
3. **`exportExcel`**: `json_to_sheet` → sheet name → `*.xlsx`.
4. **Toolbar**: right-side PDF/Excel buttons after Advanced Search (same JSX as adjustments).
5. Trans # fallback: `row.transNo || PREFIX-${String(row.id).padStart(5, "0")}`.
6. Null text fields → `"-"`. Date via `formatDateOnly(row.date, timezone)`.
7. No qty formatters needed (list rows are document headers only).

## Toolbar snippet (all three)

Same as adjustments: after left Add + Advanced Search group, add right group with PDF/Excel `Button variant="outline" size="sm"` + `FileDown`, `flex-1 sm:flex-none`, `border-[#ccc]`.

## Steps

1. Transfers table: imports → exportPDF/exportExcel → toolbar → `npx tsc --noEmit`
2. Releasings table: same
3. Receivings table: same
4. Final `npx tsc --noEmit`

## Out of scope

- Detail pages / `printDocumentPdf` / item-level line exports
- Export permission API (locations pattern has none)
- Columns files — no change required

## Verification

1. `npx tsc --noEmit` clean
2. Each page toolbar shows PDF + Excel
3. Files download: `transfers.*`, `releasings.*`, `receivings.*` with Status column
4. Data matches current list page filter/page
5. Existing Add / Search / detail navigation unchanged
