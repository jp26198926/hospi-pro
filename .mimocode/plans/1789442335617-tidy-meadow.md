# Plan: Trans Type module

Full CRUD module **Trans Type** (Transaction Type) — DB → validation → API → UI → sidebar.

Copy **Payment Terms** as the primary template (same simple shape: unique name + status + audit). Payment Method/UOM as secondary UI refs.

**User decisions**
- Code naming: **short** — `transTypes` / `trans_types` / `/trans-types`
- Sidebar label: **Trans Type**, icon **`tag`**
- `name`: required, unique
- `status`: `commonStatusEnum`, default `Active`
- Detail page `/trans-types/[id]` — yes
- Audit fields — yes (project standard)

## Step 1 — Schema + migration

**File:** `lib/db/schema.ts` — after `paymentTerms`:

```ts
export const transTypes = pgTable("trans_types", {
  id: bigserial("id", { mode: "number" }).primaryKey(),
  name: text("name").notNull().unique(),
  status: commonStatusEnum("status").notNull().default("Active"),
  createdAt: timestamp("created_at", { withTimezone: true, mode: "date" }).defaultNow().notNull(),
  updatedAt: timestamp("updated_at", { withTimezone: true, mode: "date" }),
  deletedAt: timestamp("deleted_at", { withTimezone: true, mode: "date" }),
  createdBy: bigint("created_by", { mode: "number" }).references((): AnyPgColumn => users.id),
  updatedBy: bigint("updated_by", { mode: "number" }).references((): AnyPgColumn => users.id),
  deletedBy: bigint("deleted_by", { mode: "number" }).references((): AnyPgColumn => users.id),
  deletedReason: text("deleted_reason"),
});
```

- Reuse `commonStatusEnum`. No extra domain columns.
- DB unique on `name` is global (includes soft-deleted); app uniqueness uses `ne(status, "Deleted")`.

```bash
npm run db:push
```

## Step 2 — Validation

**File:** `lib/validations/trans-type.ts`

```ts
import { z } from "zod";

export const transTypeSchema = z.object({
  name: z.string().trim().min(1, "Name is required").max(100),
});

export const transTypeUpdateSchema = z.object({
  name: z.string().trim().min(1, "Name is required").max(100),
  status: z.enum(["Active", "Deleted"]).optional(),
});

export type TransTypeInput = z.infer<typeof transTypeSchema>;
export type TransTypeUpdateInput = z.infer<typeof transTypeUpdateSchema>;
```

- Form uses **create** schema only.
- API PUT also uses **create** schema (project convention). Forms never send status.

## Step 3 — API list + create

**File:** `app/api/trans-types/route.ts`

Template: `app/api/payment-terms/route.ts` (strip termDays).

**GET** — `requirePermission(request, "/trans-types", "Read")`
- Params: `page` (1), `limit` (10, max 100), `search`, `sortBy` (def `createdAt`), `sortOrder` (def `desc`), `status` (`all`|`Active`|`Deleted`)
- Search: `ilike(transTypes.name, %search%)`
- Sort map: `name` | `status` | `updatedAt` | else `createdAt`
- `Promise.all` data + count → `{ data, total, page, limit }`

**POST** — `requirePermission(..., "/trans-types", "Add")`
- `transTypeSchema.safeParse` → 400
- Uniqueness: `and(eq(name, value), ne(status, "Deleted"))` → 409 `"Trans type name already exists"`
- Insert `{ name, createdBy: auth.userId }` (status defaults Active in DB)
- `{ data }` status 201

## Step 4 — API single resource

**File:** `app/api/trans-types/[id]/route.ts`

Template: payment-terms `[id]` route.

| Method | Permission | Behavior |
|---|---|---|
| GET | Read | Active by id; 404 if missing |
| PUT | Edit | Create schema; uniqueness name excluding self + Deleted → 409; set `name`, `updatedAt`, `updatedBy` |
| DELETE | Delete | Soft delete + optional `{ reason }` → `deletedBy`/`deletedReason` |
| PATCH | Restore | Only Deleted; clear delete audit; set `updatedBy` |

`await params`; invalid id → 400.

**proxy.ts**: no public routes.
