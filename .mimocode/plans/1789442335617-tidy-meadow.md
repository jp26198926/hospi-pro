# Plan: Clone `/stock-movements` → `/phar-stock-movements` (Phar Stock Movements)

## Goal

Same pattern as **Phar Stock Levels**:

- Module **Phar Stock Movements** at **`/phar-stock-movements`**
- **No** DB migration
- Data from **`stock_movements`**
- **Forced filter:** location Active **`lower(name) = 'pharmacy'`**
- API + UI + page + menu grants
- Keep: trans type filter, search, date From/To, last-20 / date desc, PDF/Excel

## Location rule (server)

In `GET /api/phar-stock-movements`:

1. Resolve pharmacy location (`lower(locations.name) = 'pharmacy'`, status Active)
2. Missing → `{ data: [], total: 0, page, limit }`
3. Always `stockMovements.locationId = phar.id`
4. **Ignore** client `locationId` query param

`PHARMACY_LOCATION_NAME = "pharmacy"` — matches existing **Pharmacy** location (id 3).
