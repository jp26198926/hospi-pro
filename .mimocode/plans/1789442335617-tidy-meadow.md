# Plan: Stock Level module (read-only inventory view)

Special module: **current qty per product per location**, written by future transaction modules — **not** full CRUD.

**User decisions**
- DB fields only: `id`, `product_id`, `location_id`, `qty` (default 0.0000), `updatedAt`, `updatedBy`
- **Unique** `(productId, locationId)` — one current stock row per product/location
- **No status / soft-delete / audit trio / createdAt**
- **Read-only APIs** — GET list (+ GET by id optional); **no POST/PUT/DELETE/PATCH** yet
- **No Add/Edit modals**, no delete, **no detail page**
- Table: search + PDF/Excel; columns: Product Code, Product Name, QTY, Location, Updated At, Updated By
- Updated By → **user email** (join `users`)
- Future transactions will upsert `stock_levels` internally

**Naming**

| Layer | Value |
|---|---|
| Table export | `stockLevels` |
| Table name | `"stock_levels"` |
| API | `app/api/stock-levels/` |

**Not created (by design)**

## Step 1 — Schema + migration

**File:** `lib/db/schema.ts` — after `transTypes`:

```ts
export const stockLevels = pgTable(
  "stock_levels",
  {
    id: bigserial("id", { mode: "number" }).primaryKey(),
    productId: bigint("product_id", { mode: "number" })
      .notNull()
      .references(() => products.id),
    locationId: bigint("location_id", { mode: "number" })
      .notNull()
      .references(() => locations.id),
    qty: decimal("qty", { precision: 10, scale: 4 }).notNull().default("0"),
    updatedAt: timestamp("updated_at", { withTimezone: true, mode: "date" }).defaultNow(),
    updatedBy: bigint("updated_by", { mode: "number" }).references(
      (): AnyPgColumn => users.id
    ),
  },
  (t) => [
    uniqueIndex("stock_levels_product_location_idx").on(t.productId, t.locationId),
  ]
);
```

- `qty` matches products stock: `decimal("qty", { precision: 10, scale: 4 }).notNull().default("0")` → DB `0.0000`
- `uniqueIndex` already imported in `schema.ts`
- FKs: `bigint({ mode: "number" })` + `.notNull()`
- No `status`, `createdAt`, `deletedAt`, `createdBy`, `deletedBy`, `deletedReason`

```bash
npm run db:push
```

## Step 2 — API (read-only)

### `app/api/stock-levels/route.ts` — **GET only**

`requirePermission(request, "/stock-levels", "Read")`

**Query params**
- `page` (def 1), `limit` (def 10, max 100)
- `search` — `or(ilike(products.code), ilike(products.name), ilike(locations.name))`
- `sortBy` (def `updatedAt`) | `sortOrder` (def `desc`)
- Optional filters: `productId`, `locationId` (`all` ignored)

**Select / join** (mirror products list style):

```ts
db.select({
  id: stockLevels.id,
  productId: stockLevels.productId,
  productCode: products.code,
  productName: products.name,
  locationId: stockLevels.locationId,
  locationName: locations.name,
  qty: stockLevels.qty,
  updatedAt: stockLevels.updatedAt,
  updatedBy: stockLevels.updatedBy,
  updatedByEmail: users.email,
})
  .from(stockLevels)
  .innerJoin(products, eq(stockLevels.productId, products.id))
  .innerJoin(locations, eq(stockLevels.locationId, locations.id))
  .leftJoin(users, eq(stockLevels.updatedBy, users.id))
  .where(where)
  .orderBy(orderFn(sortColumn))
```

- Count: `db.select({ value: drizzleCount() }).from(stockLevels).innerJoin(products, ...).innerJoin(locations, ...).where(where)` — include joins if search touches them
- Sort map: `productCode` → `products.code`; `productName` → `products.name`; `qty` → `stockLevels.qty`; `location` → `locations.name`; `updatedAt` → `stockLevels.updatedAt`; else `updatedAt`
- Response: `{ data, total, page, limit }`
- **Do not** filter products by Active — show all stock rows; deleted products should not appear if FK restricts, but join is enough for now

**Error message**: `"Failed to fetch stock levels"`

### `app/api/stock-levels/[id]/route.ts` — **GET one** (optional but useful for later modules)

- `requirePermission(..., "/stock-levels", "Read")`
- Same joins; 404 if missing; `{ data }`
- **No POST/PUT/DELETE/PATCH exports**

## Gotchas

- **Not** a soft-delete module — no status; do not copy uniqueness-ne-status patterns for stock itself
- `qty` arrives as **string** from Drizzle decimal — display as-is or `Number(qty).toFixed(4)`
- Count query must use the **same joins** as list when searching products/locations
- Permission cache ~30s after grants
- `products.stock` on the products table is a **separate** aggregate — Stock Level is **per location**; do not auto-sync unless asked later
- Transaction modules later: upsert on unique `(productId, locationId)`; set `updatedAt = now()`, `updatedBy = auth.userId`
- Icon `bar-chart-3` exists in `sidebar.tsx`
- Order 13 after Trans Type (12)
- Roles opening Stock Level with location filter need Read on `/locations`
