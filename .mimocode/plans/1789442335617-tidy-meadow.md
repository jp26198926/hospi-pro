# Plan: Adjustments cancel → stock_movements trans type `Adjustment Cancel`

## Goal

When a user **cancels** an adjustment, `stock_movements` must use trans type **`Adjustment Cancel`**, same as conversions cancel uses **`Conversion Cancel`**.

## Root cause

`lib/adjustment-stock.ts` cancel path resolves `getTransTypeIdByName("Adjustment")` — same as create. Conversions correctly use `"Conversion Cancel"` on cancel. Reverse qty/stock logic is already correct; **only the trans type name is wrong**.

`getTransTypeIdByName` **throws** if the name is missing — there is no seed script for `"Adjustment Cancel"`. The row must exist in `trans_types`.

## Step-by-step

### Step 1 — Code: cancel trans type

**File:** `lib/adjustment-stock.ts` (~L137)

```ts
// before
const transTypeId = await getTransTypeIdByName("Adjustment");

// after (mirror lib/conversion-stock.ts)
const cancelTypeId = await getTransTypeIdByName("Adjustment Cancel");
```

Use `cancelTypeId` on the cancel `stockMovements` insert. Leave create path as `"Adjustment"`.

### Step 2 — Ensure trans type row exists

Active `trans_types` row with `name = "Adjustment Cancel"` (and typically `status = "Active"`).

Implementation options (do both if needed):
1. Check via one-off node/psql using `.env.local` `DATABASE_URL` (read-only SELECT first).
2. If missing: **POST `/api/trans-types`** as Admin, or insert via a short node script using the same Drizzle setup as other seeds (`dotenv-cli` + `lib/db`).

No permanent seed script required unless you want one; project pattern is CRUD + one-time DB setup for trans types (Receiving Cancel, Conversion Cancel, etc. already assumed present).

### Step 3 — Docs (short)

**AGENTS.md** (outside auto-block) adjustments bullet: cancel writes stock_movements with trans type **`Adjustment Cancel`**.

Optional: `MODULE_CREATION.md` inventory note if it lists trans types.

### Step 4 — Typecheck

`npx tsc --noEmit`

### Step 5 — Verify (manual)

1. Confirm `Adjustment Cancel` exists: `/trans-types` or `SELECT * FROM trans_types WHERE name = 'Adjustment Cancel'`.
2. Create a completed adjustment → `stock_movements` has trans type **Adjustment**.
3. Cancel it → new `stock_movements` row with **Adjustment Cancel** and reverse qty sign; `stock_levels` / `products.stock` still reverse.
4. Stock Movements list shows the cancel type name.
5. Conversions cancel still uses **Conversion Cancel**.
