# Plan: Clone `/adjustments` → `/phar-adjustments` + `/conversions` → `/phar-conversions`

## Goal

Pharmacy-scoped clones (same pattern as phar-stock-levels / phar-stock-movements):

| Module | Path | Menu name |
|--------|------|-----------|
| Phar Adjustments | `/phar-adjustments` | **Phar Adjustments** |
| Phar Conversions | `/phar-conversions` | **Phar Conversions** |

- **No** DB migration — same `adjustments` / `conversions` tables
- **Location always pharmacy** (`lower(locations.name) = 'pharmacy'`, Active) — existing location id **3**
- Full UI clone: list, Advanced Search, Add, View, Cancel, PDF/Excel list export
- **List GET:** always filter `locationId = pharmacy.id` (ignore client locationId)
- **Add / POST:** **force** `locationId = pharmacy.id` server-side (do not trust form)
- **Cancel / [id]:** only allow if document location is pharmacy
- Search modal: **no** Location dropdown
- Form: Location **locked** (readonly “Pharmacy”); still post locationId = pharmacy

**Permissions (page paths):**
- `/phar-adjustments`: View, Read, Add, Edit, Delete, Restore, Export (match Admin `/adjustments` grants)
- `/phar-conversions`: same for conversions
- Stock engines unchanged (`createAdjustment` / `createConversion` / cancel helpers)

---

## Shared helpers

`const PHARMACY_LOCATION_NAME = "pharmacy"` in each phar API (same as phar-stock-*).

Resolve once per request; if missing → empty list / POST 400 `Pharmacy location not found`.

## 1. Phar Adjustments

### API

| File | Methods | Rules |
|------|---------|--------|
| `app/api/phar-adjustments/route.ts` | GET list, POST create | `requirePermission("/phar-adjustments", "Read"\|"Add")`; GET forces pharmacy; POST overrides `locationId` to pharmacy then same validation as `/api/adjustments` + `createAdjustment` |
| `app/api/phar-adjustments/[id]/route.ts` | GET one, DELETE cancel, PATCH restore if parent has it | Load doc; **403/404** if `locationId !== pharmacy.id`; cancel uses `cancelAdjustment`; permission path `/phar-adjustments` Delete/Restore |

Clone list select/joins from `app/api/adjustments/route.ts` (location name, product, uom, qty fields, audit display, date filters). Status filter `all|Completed|Cancelled` as today.

### UI

```
app/(admin)/phar-adjustments/page.tsx
components/phar-adjustments/
  phar-adjustments-table.tsx
  phar-adjustments-columns.tsx   # or reuse getAdjustmentColumns
  phar-adjustment-form-modal.tsx # location locked to Pharmacy
  phar-adjustment-search-modal.tsx # no location filter
  phar-adjustment-view-cancel-modals.tsx
```

- Fetch `/api/phar-adjustments` for list + mutations
- Form POST `/api/phar-adjustments`; cancel DELETE `/api/phar-adjustments/{id}`
- Location field: disabled SearchableSelect or static text **Pharmacy**; do not load multi-location list
- Product filter on search still allowed
- Defaults: limit 20, status all, date desc; PDF/Excel `phar-adjustments.*`
- Title: **Phar Adjustments**
