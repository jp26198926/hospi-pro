# UOM (Unit of Measure) Module — Full CRUD

Fields: `code` (unique, required), `name` (unique, required), `status` (commonStatusEnum, default Active).

## Files

### 1. Schema — `lib/db/schema.ts` (append after `locations`)

```ts
export const uoms = pgTable("uoms", {
  id: serial("id").primaryKey(),
  code: text("code").notNull().unique(),
  name: text("name").notNull().unique(),
  status: commonStatusEnum("status").notNull().default("Active"),
  createdAt: timestamp("created_at", { withTimezone: true, mode: "date" }).defaultNow().notNull(),
  updatedAt: timestamp("updated_at", { withTimezone: true, mode: "date" }),
  deletedAt: timestamp("deleted_at", { withTimezone: true, mode: "date" }),
});
```

Then `npm run db:push`.

### 2. Validation — `lib/validations/uom.ts`

```ts
export const uomSchema = z.object({
  code: z.string().min(1, "Code is required").max(20),
  name: z.string().min(1, "Name is required").max(100),
});
export const uomUpdateSchema = z.object({
  code: z.string().min(1, "Code is required").max(20),
  name: z.string().min(1, "Name is required").max(100),
  status: z.enum(["Active", "Deleted"]).optional(),
});
```

### 3. API — `app/api/uoms/route.ts` + `app/api/uoms/[id]/route.ts`

Standard CRUD with `requirePermission(request, "/uoms", ...)`. Uniqueness checks on BOTH code and name.

### 4. Components — `components/uoms/` (5 files)

Columns: `code`, `name`, `status`, `createdAt`, `updatedAt`, `actions`. Form modal has both code + name inputs.

### 5. Pages — `app/(admin)/uoms/` (3 files)

`layout.tsx`, `page.tsx` (with `requirePageRead("/uoms")` + timezone), `[id]/page.tsx`.

### 6. Sidebar + grants

Insert into `pages` under Data (id=8): `('UOM', '/uoms', 'bookmark', 6, 'Active')`. Grant Administrator all permissions.

## Verification

1. `npm run db:push` succeeds
2. `npx tsc --noEmit` passes
3. Sidebar shows UOM under Data
4. Full CRUD works (create with code+name, edit, delete, restore)
5. Duplicate code or name returns 409
