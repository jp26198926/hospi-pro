## Step 1 — Schema + migration

**File:** `lib/db/schema.ts` — append after similar tables (e.g. near `uoms` / `suppliers`):

```ts
export const paymentMethods = pgTable("payment_methods", {
  id: bigserial("id", { mode: "number" }).primaryKey(),
  name: text("name").notNull().unique(),
  description: text("description").notNull().unique(),
  status: commonStatusEnum("status").notNull().default("Active"),
  createdAt: timestamp("created_at", { withTimezone: true, mode: "date" }).defaultNow().notNull(),
  updatedAt: timestamp("updated_at", { withTimezone: true, mode: "date" }),
  deletedAt: timestamp("deleted_at", { withTimezone: true, mode: "date" }),
  createdBy: bigint("created_by", { mode: "number" }).references((): AnyPgColumn => users.id),
  updatedBy: bigint("updated_by", { mode: "number" }).references((): AnyPgColumn => users.id),
  deletedBy: bigint("deleted_by", { mode: "number" }).references((): AnyPgColumn => users.id),
  deletedReason: text("deleted_reason"),
});
```

- Reuse existing `commonStatusEnum` — no new enum.
- DB unique indexes on `name` and `description` are **global** (include soft-deleted). App uniqueness checks still use `ne(status, "Deleted")` — same pattern as products/UOM; document the gotcha in MODULE_CREATION if adding examples later.

```bash
npm run db:push
```

(No `drizzle/` migrations in repo — project practice is `db:push` only.)

## Step 2 — Validation

**File:** `lib/validations/payment-method.ts`

```ts
import { z } from "zod";

export const paymentMethodSchema = z.object({
  name: z.string().trim().min(1, "Name is required").max(100),
  description: z.string().trim().min(1, "Description is required").max(255),
});

export const paymentMethodUpdateSchema = z.object({
  name: z.string().trim().min(1, "Name is required").max(100),
  description: z.string().trim().min(1, "Description is required").max(255),
  status: z.enum(["Active", "Deleted"]).optional(),
});

export type PaymentMethodInput = z.infer<typeof paymentMethodSchema>;
export type PaymentMethodUpdateInput = z.infer<typeof paymentMethodUpdateSchema>;
```

- Form modal uses **create** schema only.
- API PUT uses **create** schema (project convention), not update schema.

## Step 3 — API list + create

**File:** `app/api/payment-methods/route.ts`

Copy structure from `app/api/suppliers/route.ts`.

**GET** — `requirePermission(request, "/payment-methods", "Read")`
- Query: `page` (def 1), `limit` (def 10, max 100), `search`, `sortBy` (def `createdAt`), `sortOrder` (def `desc`), `status` (`all` | `Active` | `Deleted`)
- Search: `or(ilike(paymentMethods.name, %search%), ilike(paymentMethods.description, %search%))`
- Sort map: `name` | `description` | `status` | `updatedAt` | else `createdAt`
- `Promise.all` data + `drizzleCount`
- Response: `{ data, total, page, limit }`

**POST** — `requirePermission(..., "/payment-methods", "Add")`
- `paymentMethodSchema.safeParse` → 400 first issue message
- Uniqueness **name**: `and(eq(name, value), ne(status, "Deleted"))` → 409 `"Payment method name already exists"`
- Uniqueness **description**: same → 409 `"Payment method description already exists"`
- Insert: `{ name, description, createdBy: auth.userId }`
- Response: `{ data }` status 201

## Step 4 — API single resource

**File:** `app/api/payment-methods/[id]/route.ts`

Copy `app/api/suppliers/[id]/route.ts`. Always `await params`; `parseInt` → 400 Invalid ID.

| Method | Permission | Behavior |
|---|---|---|
| GET | Read | By id + `ne(status, "Deleted")`; 404 if missing → `{ data }` |
| PUT | Edit | Create schema; 404 if missing; uniqueness name + description excluding self + Deleted → 409; `.set({ name, description, updatedAt: new Date(), updatedBy: auth.userId })` |
| DELETE | Delete | Soft delete; optional body `{ reason }` → `deletedReason`; set `status: "Deleted"`, `deletedAt`, `deletedBy: auth.userId` → `{ message }` |
| PATCH | Restore | Find only Deleted; set `status: "Active"`, clear `deletedAt`/`deletedBy`/`deletedReason`, set `updatedAt`/`updatedBy` → `{ data }` |

**proxy.ts**: do **not** add `/api/payment-methods` to `PUBLIC_API_ROUTES` or `PUBLIC_PAGES`.
