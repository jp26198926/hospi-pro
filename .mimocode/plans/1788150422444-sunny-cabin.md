### 7. Architecture Notes
- **Auth**: JWT access tokens (15min) + refresh tokens (7 days, httpOnly cookie)
- **proxy.ts**: Next.js 16 middleware — protects routes, redirects unauthenticated users to `/login`
- **Route groups**: `(admin)` = protected pages with sidebar, `(auth)` = public pages
- **Dynamic sidebar**: Built from `pages` table in DB
- **File uploads**: Configurable — File System (local) or Cloudinary (via settings)
- **App settings**: Logo, favicon, name, storage type — all configurable from `/settings-application`

### 8. How to Add a New Module (Step-by-Step Guide)

**Example: Adding a "Categories" module**

#### Step 1: Database Schema
Add table to `lib/db/schema.ts`:
```ts
export const categories = pgTable("categories", {
  id: serial("id").primaryKey(),
  category: text("category").notNull().unique(),
  status: commonStatusEnum("status").notNull().default("Active"),
  createdAt: timestamp("created_at").defaultNow().notNull(),
  updatedAt: timestamp("updated_at"),
  deletedAt: timestamp("deleted_at"),
});
```
Run: `npm run db:push`

#### Step 2: Validation Schema
Create `lib/validations/category.ts`:
```ts
import { z } from "zod";

export const categorySchema = z.object({
  category: z.string().min(1, "Category name is required").max(100),
});

export type CategoryInput = z.infer<typeof categorySchema>;
```

#### Step 3: API Route
Create `app/api/categories/route.ts`:
- `GET` — list all (with search/pagination)
- `POST` — create new

Create `app/api/categories/[id]/route.ts`:
- `GET` — get one
- `PUT` — update
- `DELETE` — soft delete (set status to "Deleted")

#### Step 4: UI Component
Create `components/categories/categories-table.tsx` — data table with search, status filter, actions (edit/delete/restore)

Create `components/categories/category-form-modal.tsx` — create/edit modal

Create `components/categories/category-delete-modal.tsx` — delete confirmation

#### Step 5: Page
Create `app/(admin)/categories/page.tsx` — wraps the table component

Create `app/(admin)/categories/layout.tsx`:
```tsx
export default function CategoriesLayout({ children }: { children: React.ReactNode }) {
  return <>{children}</>;
}
```

#### Step 6: Register in Sidebar
The sidebar is dynamic — add the module to the `pages` table in the database:
```sql
INSERT INTO pages (page, path, icon, "order", status)
VALUES ('Categories', '/categories', 'folder', 5, 'Active');
```

#### Step 7: Add API to Proxy (if needed)
Add to `PUBLIC_API_ROUTES` in `proxy.ts` if the endpoint should be publicly accessible.

### 9. Contributing
- Create a feature branch from `main`
- Follow existing patterns (schema → validation → API → component → page)
- Run `npm run lint` before committing
- Use soft deletes (`status: "Deleted"`) — never hard delete
- All API routes require Bearer token auth unless added to `PUBLIC_API_ROUTES`
